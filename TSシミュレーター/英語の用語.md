# 英語の表示で使っている用語（確認用）

画面を英語にしたときに使っている、測量の用語とボタンの名前の一覧です。一般的な言い方を選んでいます。直したいものがあれば、この表を直すように言ってください（コア・画面・AIの指示の3か所を、まとめて直します）。

- 画面の文：コア（`crates/core`）と辞書（`src/ui/i18n.tsx`）
- AIへの指示：中継（`relay/api/ai.ts` の `ENGLISH`）。AIの答えも、この用語にそろえるよう指示しています

## ボタンの名前

| 日本語 | 英語 |

| はじめる | Start |

## そのままのもの

- 単位（mm・m）と、角度の書き方（度分秒 例：+0°00′14″）
- 点名（T-1 など）、整準ネジの名前（A・B・C）、脚の番号（Leg 1〜3）
- AIに渡す「事実」は日本語のまま（AIが英語に直して答える）
