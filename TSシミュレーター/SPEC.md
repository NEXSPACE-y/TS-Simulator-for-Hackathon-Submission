## 1. 概要

### 1.1 何を作るか
トータルステーション（以下TS）の**据付から観測（BS・FS）まで**を、ブラウザ上の3Dで練習できるシミュレーター。

### 1.2 なぜ作るか
- TSは高額で個人では持てない。会社の器械は現場で使用中のため、新人は**現場でしか練習できない**。
- 教科書の据付手順と、現場で実際に行う手順には差がある。そのギャップを埋める練習台がない。
- 作者自身が測量見習いとして「実地以外で練習したい」と感じたことが出発点。

### 1.3 対象ユーザー
- 測量会社・建設会社の新人
- 測量を学ぶ学生（高校・専門学校）
- 新人教育を担当する先輩・指導者

### 1.4 作品の核（審査で一番見せたいこと）
**求心と整準の「片方を直すと、もう片方がズレる」ループ**を、実機に近い感覚で再現すること。

### 1.5 技術面の特徴
**計算のコアをRustで書き、WebAssembly（WASM）にしてWeb版とデスクトップ版で同じものを使う。** 物理と判定はRust、TypeScriptは表示だけ、という役割分担。

## 2. 配布形態

| 形態 | 役割 | 公開先 |
|---|---|---|
| Web版（主） | 審査員がURLを開くだけで触れる | Vercel |
| デスクトップ版（副） | 同じ中身をTauriで包んだもの | GitHub Releases（GitHub Actionsで自動ビルド） |

- Web版とデスクトップ版は**同じリポジトリ**で管理する。
- 3つの層に分ける：
  - **計算のコア（Rust → WASM）**：状態・物理・判定・観測の計算・タイマー
  - **3D描画（TypeScript＋Three.js）**：Three.jsを直接使う。React Three Fiberは使わない
  - **UIパネル（TypeScript＋React）**
- **物理・判定・座標計算はすべてRustのコアに置く。** TypeScript側には計算を書かず、コアの結果を表示するだけにする。
- デスクトップ版も**Web版と同じWASMをWebView内で動かす**。Tauri（Rust側）からコアを直接呼ばない（Web版と挙動が分かれるのを防ぐ）。Tauri側はファイル保存などOS固有の処理のみ。
- 気泡の値など毎フレーム変わる数値はReactの状態に入れず、表示を直接書き換える（再描画の連発でカクつくのを防ぐ）。
- WASMとのやり取りは**1フレームにつき「操作を渡す」「結果をまとめて受け取る」の最小限**にする（境界をまたぐ回数を減らすため）。

## 5. 手順

### 5.1 第1部：据付（現場の手順）

| No | 手順 |
|---|---|
| 1 | 三脚を測点の上に置く |
| 2 | 一点を踏み込み、残り二点で鉛直を仮合わせ |
| 3 | 残り二点も踏み込む |
| 4 | 三脚の足の伸縮で円形気泡を合わせる |
| 5 | 整準ネジ3本で電子気泡を合わせる |
| 6 | 求心がズレていれば、定心桿を緩めて三脚頭の上で器械をずらして合わせる |
| 7 | 再度、整準ネジで電子気泡を合わせる |

- **求心と電子気泡の両方が許容内に入るまで、6⇄7を繰り返す。**
- 器械は手順2の前の時点で定心桿で三脚に固定済みとする。
- **ループ回数**：手順6（器械ずらし）を行った回数で数える。

### 5.2 第2部：観測

| No | 手順 |
|---|---|
| 8 | 電子平板で機械点とBSをセット |
| 9 | BSを視準して測量 |
| 10 | FSのプリズムを視準して測量 |

- 第2部は第1部の据付が合格してから進める。

### 5.3 モード

| モード | 内容 |
|---|---|
| 教科書モード | 教科書の一般的な手順を一歩ずつガイドする。手順外の操作をすると注意を表示 |
| 現場モード | 5.1の現場手順。順番は自由で、最後に求心と電子気泡が許容内なら合格 |

教科書モードの手順（一般的な流れ。**本番前に教本で要確認**）：
1. 三脚を測点の上におおよそ置き、脚頭をだいたい水平に
2. 器械を載せて定心桿で固定
3. 整準ネジで求心点を測点に合わせる
4. 三脚の足の伸縮で円形気泡を中央へ
5. 整準ネジで精密に整準
6. 求心がズレていれば定心桿を緩めて器械をずらす
7. 整準を確認。両方合うまで5〜6を繰り返す

### 5.4 タイムと結果
- タイムは**最初の操作で開始**し、**「据付完了」ボタンを押した時点で停止**する。
- 「据付完了」を押した時点で、求心ズレと電子気泡が許容内なら合格。許容外なら不合格の理由（どちらが何mm／何秒外れているか）を表示し、続行できる。
- 定心桿が緩んだままの「据付完了」は不合格とする。
- 目安：**3分で合格、2分で熟練**。
- 結果画面に、タイム・ループ回数・最終の求心ズレと電子気泡の値を表示する。

### 5.5 今回入れないもの
- TSの起動待ち時間と、その間に電子平板を準備する段取りの再現
- 器械の起動・設定メニューの細かい再現
- 記録の保存・ランキング

## 6. シミュレーションの中身

### 6.1 基本方針
**整準ネジ・気泡・液晶・レーザーの4つは、すべて1つの状態（三脚と器械の位置・傾き）から計算する。**
どれか1つを操作すれば、他の表示も必ず連動して変わる。これで6⇄7のループが自然に再現される。
状態と計算はすべてRustのコアが持つ。

### 6.2 状態（State）
| 項目 | 内容 |
|---|---|
| 三脚の脚 ×3 | 足先の地面上の位置、脚の長さ、踏み込み済みか |
| 三脚頭 | 脚から計算される位置と傾き |
| 器械の三脚頭上のずれ | 定心桿を緩めて動かせる量（X・Y） |
| 整準ネジ ×3 | それぞれの回転量 |
| 定心桿 | 締めている／緩めている |
| 測点 | 地面上の位置（原点） |
| 望遠鏡（第2部） | 水平角・鉛直角（粗動・微動の操作量を反映） |
| 電子平板（第2部） | 選んだ機械点・BS点、入力した器械高、観測結果 |

内部の単位は **mm と ラジアン**。計算は64bit浮動小数点（f64）で行う。表示時に変換する。

### 6.3 計算するもの（Derived）
| 項目 | 計算の考え方 |
|---|---|
| 器械の傾き | 三脚頭の傾き＋整準ネジ3本が作る面の傾き |
| 円形気泡 | 傾きに応じて気泡管の中を移動。中心の円に入れば合格 |
| 電子気泡（液晶） | ◎の中の点の位置＋X・Yの数値 |
| レーザー求心点 | 器械の鉛直軸を下に延ばして地面と交わる点。傾くと器械高×tan(傾き)だけズレる |
| 求心ズレ | レーザー求心点と測点の距離（mm） |
| 器械高 | 三脚頭の高さ＋器械の寸法から計算 |
| 視準のズレ（第2部） | 十字線とターゲット中心の角度差 |
| 観測結果（第2部） | BSで方向角の基準を決め、FSの水平角・距離から座標を計算 |

### 6.4 必ず守る挙動
- **左手親指の法則**：整準ネジ2本を同時に内側または外側に回すと、気泡は左手親指を回す方向に動く。
- 整準ネジ1本だけを回すと、そのネジの方向に傾きが変わる。
- 器械を三脚頭の上でずらしても、傾きはほぼ変わらない（ずらす量が小さいため）。ただし三脚頭自体が傾いていると、わずかに気泡が崩れる。
- 定心桿を締めている間は、器械をずらせない。
- 整準すると傾きが変わるので、レーザー求心点が動く。
- 三脚の足を伸縮すると、三脚頭が傾き、円形気泡が動く。求心点はあまり動かない。

### 6.5 再現の優先度
| 優先度 | 対象 |
|---|---|
| **完全再現** | 整準ネジ、円形気泡、液晶（電子気泡）、レーザー求心 |
| それなり | TS本体の外観、三脚、地面、プリズム |

- TS本体は**一目でTSと分かればよい**。特定メーカーの製品に似せない。メーカーのロゴ・名前は入れない。
- 電子平板の画面も、特定製品の画面を真似ない。汎用的なデザインにする。

### 6.6 液晶表示
- **◎のタイプ**：外側の円の中に点が表示され、中心の円に入ると許容内。
- その下に **X・Yの数値を度分秒で表示**。例：`X: +0°00′12″` ／ `Y: −0°00′08″`
- 整準ネジを回すと、点と数値がリアルタイムで動く。
- 許容内で色が変わる・音が鳴る、といった演出は入れない。

### 6.7 許容値と範囲
| 項目 | 値 | 状態 |
|---|---|---|
| 求心ズレの許容 | **0.5 mm 以内** | 確定 |
| 電子気泡の許容 | **±15″ 以内**（X・Yそれぞれ） | 確定 |
| 液晶◎の外側の円の範囲 | ±6′ | 仮 |
| 円形気泡の感度 | 8′ / 2 mm | 仮 |
| 器械を三脚頭上でずらせる範囲 | ±20 mm | 仮 |
| 器械高 | 1500 mm 前後 | 仮 |
| 視準OKの範囲（第2部） | 十字線とターゲット中心の差 | 仮（値は動かして決める） |

- 数値はすべてRustのコアの設定ファイル1か所にまとめる。

## 8. 第2部：観測の中身

### 8.1 電子平板（手順8）
- 既知点の一覧から、機械点とBS点を選ぶ。
- 器械高を入力する。

### 8.2 視準（手順9・10）
- 望遠鏡の視野を表示し、十字線をターゲットに合わせる。
- 水平・鉛直の粗動と微動で操作する。
- 十字線がターゲット中心から一定範囲内なら視準OK。

### 8.3 測量
- BS：観測して方向角の基準を確定する。
- FS：プリズムを視準して観測し、座標を表示する。設計値との差も表示する。

## 9. 3Dと動作の軽さ

### 9.1 目標
- 作者の手元で確認できる機械は **Core i5-6200U（内蔵GPU HD 520）** のみ。
- **最低ライン**：この機械で普通に操作でき、デモ動画の録画がカクつかないこと。
- 数値の目標（fps）は設けない。重い場合は画質を落として対応する。

### 9.2 方針
- 形はシンプルに、質感は画像（テクスチャ）で表現する。
- 動的な影は1灯のみ（器械と三脚の影）。地面の陰影は焼き込み。
- ブルームなどの重い後処理は使わない。
- 描画解像度（pixel ratio）に上限を設ける。
- 「軽量／標準」の画質切替を付ける。
- WASMのファイルは本番ビルドで最適化し、サイズを小さくする。

## 11. テスト

物理・判定・計算の挙動はRustの自動テスト（`cargo test`）で確認する。最低限：

- 整準ネジ2本を同時に回したとき、気泡が左手親指の方向に動く
- 傾きθ・器械高hのとき、レーザー求心点のズレが h×tanθ になる
- 器械を三脚頭上でずらすと、求心ズレがその分だけ変わる
- 定心桿を締めている間は、器械がずれない
- 6⇄7を繰り返すと、求心ズレと電子気泡の両方が許容内に収束できる
- 「据付完了」の合否判定（許容の境界値、定心桿が緩んだままの場合）
- 度分秒の表示変換（符号、繰り上がり）
- BS・FSの観測から計算した座標が、既知の答えと一致する

WASMとのつなぎ目は、Vitestで最低限確認する（WASMが読み込めること、操作を渡すと結果が返ること）。
