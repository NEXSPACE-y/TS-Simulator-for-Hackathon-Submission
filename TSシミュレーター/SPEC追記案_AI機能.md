## 14. AI先輩（追記案）

### 14.1 何をするか

シミュレーターの中に「AI先輩」（Claude）を置き、次の5つを行う（ほかに、教科書モードの音声ナビ。14.8）。

| No | 機能 | どこで | 使うモデル |
|---|---|---|---|
| 1 | 据付の講評：操作の記録から、遠回りしたところと次のコツを話す | 「据付完了」の結果画面の「AI先輩の講評を聞く」 | Claude Opus 5.5 |
| 2 | 何でも質問：いまの状態を踏まえて答える | 上部の「AI先輩」ボタン | Claude Sonnet 5.5 |
| 3 | 観測の解説：FSの座標がどう計算されたかを、実際の数字で順に話す | FSの観測結果の「AI先輩に計算を説明してもらう」 | Claude Opus 5.5 |
| 4 | 現場の指示の聞き取り：先輩が口頭風に指示し、そのとおりに電子平板をセットできるかを練習する | 手順8（電子平板）の「先輩の指示を聞く」 | Claude Opus 5.5 |
| 5 | 操作中のひとこと：つまずいたときに短く声をかける | 3Dビューの左下（「AI先輩」の中で切り替え） | Claude Haiku 5.5 |

### 14.2 決まり：「正解はRust、言葉はAI」

- 合否・数値・座標・**どのネジをどちらへ回すか・どちらへずらすか**・ひとことを出すきっかけは、**すべて Rust のコア（`crates/core/src/coach.rs` など）が決める**。`cargo test` で確かめる。
- AIには、コアが作った「事実」（見出しと値の組）だけを渡し、**言葉にさせるだけ**にする。AIに新しい判断はさせない（左手親指の法則を逆に言う、などの誤りを防ぐため）。
- 次の操作の向きは、コアが**実際に少しだけ回して（伸縮・ずらして）みて、良くなるほうを選ぶ**。決め打ちの表は使わない。
- 「次の操作のとおりに操作すると、両モードとも据付が合格まで行く」ことを `cargo test` で確かめる（始まり方6通りずつ）。
- AIを呼ぶのは、ボタンを押したときと、ひとことのきっかけが出たときだけ。毎フレームは呼ばない。

### 14.3 操作の記録（コア）

- 操作の種類か手順が変わるごとに1件記録する（毎フレームではない。上限400件）。
- 集計：手順ごとの時間、手順の流れ、整準ネジを1本ずつ回した時間と2本同時の時間、目標が悪くなる向きに回していた時間、脚の伸縮・器械ずらしの時間、ループごとのずらす前の求心ズレと電子気泡、定心桿を締めたままずらそうとした回数、整準ネジを回しきった回数、教科書モードの手順外の注意の回数、不合格だった「据付完了」の回数。
- 「遠回り」の判定（仮）：
  - 悪くなる向きに整準ネジを回していた時間が合計3秒以上
  - 電子気泡が±60″より大きくずれたまま、器械をずらした
  - ループが3回を超えた
  - 整準ネジを回しきった
  - 手順の基準タイムを超えた（超え方の大きい2つまで）
  - 許容に入る前に「据付完了」を押した／定心桿を締めたままずらそうとした／手順外の操作（教科書モード）

### 14.4 操作中のひとこと（コア）

- きっかけ（仮）：
  1. 手順の基準タイムを過ぎた（手順ごとに1回）
  2. 整準ネジを、悪くなる向きに2秒続けて回している（整準の段階だけ。60秒あけて繰り返す）
  3. 整準ネジを回しきった（1回）
  4. ループが4回になった（1回）
  5. 電子気泡が±60″より大きくずれたまま、器械をずらし始めた（1回）
- ひとことは30秒以上あけて出す。ひとことの中身もコアが決め、AIは言い方を整えるだけ。AIが使えないときは、コアの中身をそのまま出す。
- 両モードで出す。最初は「出す」。上部の「AI先輩」の中で切り替えられる（切り替えはブラウザに覚えておく）。

### 14.5 現場の指示の聞き取り（コア）

- 指示する点はコアが決める：機械点＝据えた点（T-1）、BS点＝ターゲットが立っている点（T-2）、器械高＝巻尺で測って入れる（数字は言わない）。3DのBSターゲットはT-2に固定（オーナー決定）なので、それに合わせる。
- 言い回しはAIが作る。中継が、指示の文に機械点とBS点の点名が入っていて、ほかの点名が無いことを確かめる。合わなければ決まった言い方にする。
- 指示のあとに「セット」を押すと、コアが「指示どおりか」を判定して表示する（機械点・BS点・器械高。器械高は巻尺で測った値との差が±2 mm以内なら指示どおり。仮）。
- 指示は画面に文字で出し、ブラウザの読み上げでも聞ける（「もう一度聞く（音声）」）。

### 14.6 中継（Vercel Functions）

- Web版は GitHub Pages のまま。Claude API を呼ぶ中継だけを Vercel Functions（`relay/`）に置く。デスクトップ版も同じ中継を呼ぶ（Tauri の CSP は今は指定なしなので、変更は不要）。
- **APIキーはオーナーが Vercel の環境変数 `ANTHROPIC_API_KEY` に登録する。Claude は扱わない。** コードやブラウザには出さない。
- 中継が受け付けるのは決まった形だけ：種類（5つ）、事実（60件まで。見出し40字・値240字まで）、質問（何でも質問のときだけ。200字まで）。それ以外の項目があれば断る。
- AIへの指示文（口調・コツ・言い回し）は中継の中で組み立てる。返事の長さ（max_tokens）にも上限を付ける。
- 呼べる出どころ：`https://nexspace-y.github.io` と Tauri（`tauri://localhost`、`http(s)://tauri.localhost`）。環境変数 `AI_ALLOWED_ORIGINS` で足せる（開発中の `http://localhost:5173` など）。
- 同じ出どころ（IP）から1分に20回まで（中継の実体が使い回される間だけ効く、簡単な歯止め）。本当の歯止めは、オーナーが Anthropic Console で設定する利用上限。
- 断られたとき（安全のための判定）は、Claude API の機能で別のモデルでやり直してもらう（Opus・Sonnet のみ。Haiku には無い）。それでも断られたら「答えられませんでした」と出す。
- エラーの中身は外に出さない。
- 依存関係は増やしていない（Anthropic の SDK を使わず、fetch で呼ぶ）。

### 14.7 使えないとき

- ネットにつながっていない・中継が止まっている・キーが未登録のときは、AI機能だけ「AI先輩はいま使えません」と出し、シミュレーター本体はそのまま使える。
- 操作中のひとことと指示の聞き取りは、AIが使えなくても、コアの決まった言い方で出す。
- 画面のAIの答えの下に「AIの言葉は参考です。数値と合否は、画面の表示が正しいものです。」と出す。

### 14.8 教科書モードのナビ（音声）

- 教科書モードでは、AI先輩がナビ役になり、字幕（3Dビューの左上）と読み上げで手順を案内する。現場モードには無い。
- いつ・何を案内するかはコアが決める：
  1. 手順に入ったとき（手順の名前・目標・まずやること）
  2. 手順の目標を満たしたとき（「次の手順へ」・「据付完了」を押すよう言う）
  3. 次の操作が変わったとき（例：「A・B」から「C」へ、「ずらす」から「締める」へ）。1.5秒同じままなら読む。6秒以上あける（仮）
  4. 手順外の操作をしたとき（注意。3秒以上あける。仮）
- 1と2は、AI（Claude Haiku 5.5。英語のナビは1〜2文・30語以内にし、入りきらないときは目標を省く。仮）に言い方を整えてもらってから読む（6秒待って返事がなければ、コアの文を読む。画面が英語のときは、AIの返事が日本語の倍ほどかかるので10秒待つ。仮）。3と4は、コアの文をそのまま読む（待ち時間を出さないため）。
  - 速くするために、「考える時間を取らずに答えてもらう」「Claude Sonnet 5.5 にする」も試したが、用語・ボタンの名前・数値が崩れたり抜けたりすることがあったので、この形に戻した（2026-11-04）。
- 読み上げはブラウザの音声合成を使う（素材・依存関係は増やさない）。数字の入ったかっこ書き（いまの角度など）は読まない。「声：ON/OFF」と「もう一度」のボタンを付ける。最初は「声：ON」。
- iPhone などで読み上げられるよう、「はじめる」を押したときに読み上げを使えるようにしておく。
- **手順の中身は、いまの7手順（5.3）を手本の手順とする**（オーナー決定、2026-11-03）。無料で読める教本は見つからなかった。作業規程の準則（国土地理院）には据付の手順は書かれていない（全文で確認）。公開されている資料（大学の実習手順書・現場の技術者の解説）とは、大筋で同じ。ナビの仕組みは手順の中身と切り離してあるので、手順を直してもそのまま使える。

2. **手順ごとの基準タイム**：現場モード 20・20・15・35・40・25・25 秒、教科書モード 30・5・25・35・40・25・20 秒（どちらも合計3分）。手順ごとに分けるか、全体だけにするか。
3. **講評の「遠回り」の基準**（14.3）：悪くなる向き合計3秒、ループ3回を超えたら、整準前のずらしは±60″。
4. **先輩のコツ**（いまは仮の7つ。`relay/api/ai.ts` の「先輩のコツ」）：現場で教わったコツに入れ替えたい。
   1. 三脚は、脚頭がだいたい水平で、測点の真上に来るように置くと、あとが楽になる。
   2. 踏み込みは1本ずつ。踏み込むとレーザー点が少し動くので、見ながら残りの脚で合わせる。
   3. 円形気泡は脚の伸縮で合わせる。整準ネジは電子気泡の仕上げのために残しておく。
   4. 整準ネジは2本を同時に内側か外側へ回すと、気泡は左手の親指の向きに動く。残りの1本で直角の向きを合わせる。
   5. 器械をずらすのは、整準が済んでから。ずらすと気泡が少し崩れるので、また整準する。
   6. ずらしたあとは、定心桿の締め忘れに気をつける。
   7. 「据付完了」を押す前に、求心ズレと電子気泡の両方が許容内か見る。
