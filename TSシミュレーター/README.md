# TS実習シミュレーター

トータルステーション（TS）の**据付から観測（BS・FS）まで**を、ブラウザの3Dで練習できるシミュレーターです。
Built with Claude: Japan 2026 の出展作品です。仕様は [SPEC.md](SPEC.md) にあります。

**Web版：https://nexspace-y.github.io/TS-Simulator-for-Hackathon-Submission/**
（インストールは要りません。URL を開くだけで動きます）

- 作品の核：求心と整準の「片方を直すと、もう片方がズレる」ループ（手順6⇄7）を、実機に近い感覚で再現すること
- 計算のコアは Rust で書き、WebAssembly（WASM）にしてブラウザで動かします。TypeScript 側は表示だけです
- AI先輩（Claude）が、講評・質問への答え・計算の解説・現場の指示・声のナビをします。合否と数値はコアが決め、AIは言葉にするだけです
- 画面は日本語と英語に対応しています

## 使い方

1. 最初の画面で、言語（日本語／English）、モード、画質を選び、「はじめる」を押します。
   - **教科書モード**：教科書の一般的な手順（7手順）を一歩ずつ進みます。AI先輩が字幕と声で案内し、手順外の操作をすると注意が出ます。
   - **現場モード**：現場の手順（7手順）です。順番は自由で、最後に求心と電子気泡が許容内なら合格です。
2. **第1部 据付**：右の操作盤（手順ごとに中身が変わる）と、右上の拡大表示（手順に合わせて求心・円形気泡・液晶のどれかが出る。左下の「拡大」で出し入れ）を見ながら据え付けます。視点は「全体・器械・足元・液晶」で切り替えます。
3. 求心ズレ 0.5 mm 以内、電子気泡 X・Y とも ±15″ 以内になったら「据付完了」を押します。
4. 合格すると、**第2部 観測**へ進めます。
   - 手順8：電子平板で、機械点・BS点・器械高（巻尺で測る）をセットする
   - 手順9：BS（ターゲット板）を視準して測量し、方向角の基準を決める
   - 手順10：FS（プリズム）を視準して測量し、座標と設計値との差を見る

タイムは最初の操作で始まり、「据付完了」を押すと止まります。目安は 3分で合格、2分で熟練です。
操作盤のボタンでも、キーボードでも操作できます。

### AI先輩（Claude）

| 機能 | どこで | モデル |
|---|---|---|
| **据付の講評**：操作の記録から、遠回りしたところと次のコツを話す | 結果画面の「AI先輩の講評を聞く」 | Claude Opus 5.5 |
| **何でも質問**：いまの状態を踏まえて答える | 上部の「AI先輩」 | Claude Sonnet 5.5 |
| **観測の解説**：FSの座標がどう計算されたかを、実際の数字で順に話す | FSの観測結果の「AI先輩に計算を説明してもらう」 | Claude Opus 5.5 |
| **現場の指示の聞き取り**：口頭風の指示（読み上げつき）のとおりに電子平板をセットできるか練習する | 手順8の「先輩の指示を聞く」 | Claude Opus 5.5 |
| **操作中のひとこと**：つまずいたとき（目安の時間を過ぎた、ネジを逆に回し続けている など）に短く声をかける | 3Dビューの左下（「AI先輩」の中で切り替え） | Claude Haiku 5.5 |
| **教科書モードのナビ**：いまの手順とやることを、字幕と声で案内する | 3Dビューの左上（「声：ON/OFF」「もう一度」） | Claude Haiku 5.5 |

- 決まりは「**正解はRust、言葉はAI**」です。合否・数値・座標・どのネジをどちらへ回すかは、すべて Rust のコアが決めます。AIには、コアが出した事実だけを渡し、言葉にしてもらいます。
- ナビの返事が崩れたとき（改行がある・長すぎる・度分秒の記号がある）や、返事が遅いときは、コアが作った文をそのまま読みます。
- ネットにつながっていないときは、AI機能だけ「使えません」と出ます。シミュレーターはそのまま使えます。

### キーボード操作

| 操作 | キー |
|---|---|
| 整準ネジ A（左手前） | `A`（親指を左）／ `S`（親指を右） |
| 整準ネジ B（右手前） | `K` ／ `L` |
| 整準ネジ C（奥） | `Z` ／ `X` |
| A・B を同時に内側へ／外側へ | `S`＋`K` ／ `A`＋`L` |
| 脚を伸ばす／縮める | `1` `2` `3` ／ `Q` `W` `E` |
| 三脚・器械・望遠鏡を動かす | 矢印キー（手順によって動く物が変わる） |
| 定心桿を締める・緩める | `T` |
| 細かく動かす | `Shift` を押しながら |
| 照準器でのぞく／望遠鏡でのぞく（観測） | `P` |
| 接眼レンズを回す（十字線をくっきりさせる） | `V` ／ `B` |
| 合焦つまみを回す（ピントを近くへ／遠くへ） | `F` ／ `G` |
| 測量（観測） | `Enter` |

### 動作環境

- WebGL が使えるブラウザ（パソコンの Chrome・Edge など）。
- 内蔵GPUのノートPC（Core i5-6200U・HD 520）で、普通に操作できることを確かめています。重いときは、上部の「画質」を「軽量」にします。
- 読み上げは、端末の音声合成を使います。英語で読み上げるには、端末に英語の音声が入っている必要があります。

## 作り方（Built with Claude）

- 仕様と、測量の挙動・手順は、作者（測量の現場経験者）が決めました。
- コードは Claude Code が書き、`cargo test`（物理・判定・計算）と Vitest で確かめながら進めました。
- アプリの中の AI先輩は、Claude API（Opus 5.5・Sonnet 5.5・Haiku 5.5）を中継から呼んでいます。

## 開発

必要なもの：Rust（版は `rust-toolchain.toml` で固定）、[wasm-pack](https://crates.io/crates/wasm-pack)（`cargo install wasm-pack`）、Node.js（22以降）

```
npm install          依存関係のインストール
npm run build:wasm   WASMのビルド（wasm-pack）
npm run dev          開発サーバー（先にWASMをビルドする）
npm run build        Web版のビルド（WASMのビルドを含む）
cargo test           コアのテスト
npm test             Vitest（先にWASMをビルドする）
```

### 構成

```
crates/
  core/     状態・物理・判定・観測の計算・タイマー（純粋なRust）
  wasm/     coreをTypeScriptに公開する薄い層（wasm-bindgen）
src/
  bridge/   WASMの読み込みと呼び出し（TypeScriptからコアに触る窓口）
  render/   Three.jsのシーン、モデル、カメラ
  ui/       画面のパネル（React）
  ai/       AI先輩（Claude）の中継を呼ぶ窓口
  main.tsx  起動処理
relay/      AI先輩の中継（Vercel Functions。APIキーはここの環境変数にだけ置く）
tests/      Vitest（WASMとのつなぎ目、AIの中継の確認）
```

- 物理・判定・座標計算はすべて `crates/core` にあります。許容値などの数値は `crates/core/src/config.rs` の1か所にまとめています。
- 1フレームにつき「操作を渡す」「結果をまとめて受け取る」の1回だけ WASM を呼びます。
- 3D は Three.js を直接使い（React Three Fiber は使わない）、毎フレーム変わる数値は React の状態に入れずに表示を直接書き換えます。

### テスト

- `cargo test`：左手親指の法則、傾きと器械高から求心ズレ（h×tanθ）、器械ずらしと定心桿、6⇄7ループの収束、据付完了の合否（許容の境界）、度分秒の変換、BS・FSの座標計算、操作の記録・遠回り・次の操作・ひとことのきっかけ・指示の判定、「次の操作どおりに進めると合格する」など。
- `npm test`（Vitest）：WASMの読み込みと受け渡し、中継が決まった形だけを通すこと、ナビの崩れた返事をコアの文に替えること。

### 公開

- Web版：GitHub Pages。`main` に push すると、`.github/workflows/pages.yml` でビルドして公開します（リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく）。
- `main` への push と pull request では、`.github/workflows/ci.yml` でテストとビルドを確かめます。
- デスクトップアプリ版（Tauri）は廃止し、ソースも消しました。Web版だけを公開しています。

### AI先輩の中継（Vercel Functions）

AI先輩（Claude）は、`relay/` の中継を通して呼びます。Web版はこの中継だけを呼び、APIキーは中継の環境変数にだけ置きます（コードやブラウザには出しません）。中継が受け付けるのは決まった形のデータだけで、AIへの指示文は中継の中で組み立てます。依存関係は無く、Claude API を fetch で呼んでいます。

中継の公開のしかた（中継は Git と連携していないので、`relay/` を直したら公開し直す）：

1. `relay/` で `npx vercel@latest deploy --prod` を実行する（初回はプロジェクト名を `ts-simulator-ai` にする。URL が `https://ts-simulator-ai.vercel.app` になる。別の名前にしたときは `src/ai/config.ts` の URL を変えるか、ビルド時の環境変数 `VITE_AI_RELAY_URL` で指定する）
2. Vercel のプロジェクトの Environment Variables に `ANTHROPIC_API_KEY`（Anthropic Console で作ったキー）を登録して、もう一度公開する
3. Anthropic Console で、月の利用上限を設定する（使いすぎを止める一番確かな歯止め）

- 呼べる出どころは、Web版（`https://nexspace-y.github.io`）だけです。開発サーバー（`npm run dev`）から試すときは、Vercel の環境変数 `AI_ALLOWED_ORIGINS` に `http://localhost:5173` を足します。
- 同じ出どころ（IP）からは1分に20回までにしています（簡単な歯止め）。

## 素材と表記

- 外部の画像・3Dモデル・フォント・音声などの素材は使っていません。地面・測点・ターゲットなどの質感は、すべてプログラムで描いています。読み上げは端末の音声合成です。
- 画像生成など、Claude 以外の AI を使った素材はありません。
- 既知点・設計点の座標はすべて架空のものです。実在の現場の座標ではありません。
- TS本体・電子平板の画面は、特定メーカーの製品に似せていません。ロゴ・メーカー名は入れていません。
